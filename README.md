## 🔧 Требования

### Что нужно установить:

1. **Python 3.8 или новее**
   - Проверьте версию: откройте терминал и введите `python3 --version`
   - Если Python не установлен, скачайте с [python.org](https://www.python.org/downloads/)
   - ⚠️ При установке обязательно отметьте галочку "Add Python to PATH"

2. **Telegram Bot Token**
   - Создайте бота через [@BotFather](https://t.me/BotFather) в Telegram
   - Отправьте команду `/newbot` и следуйте инструкциям
   - Сохраните полученный токен (выглядит как `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

## ⚙️ Первоначальная настройка

### Шаг 1: Установка зависимостей

Откройте терминал (на Mac: `Cmd + Space`, введите "Terminal"; на Windows: `Win + R`, введите `cmd`).

Перейдите в папку с ботом:
```bash
cd /Users/gleb/Desktop/to/ugra-to-bot
```

Создайте виртуальное окружение (изолированная среда для проекта):
```bash
python3 -m venv .venv
```

Активируйте виртуальное окружение:
- **На Mac/Linux:**
  ```bash
  source .venv/bin/activate
  ```
- **На Windows:**
  ```bash
  .venv\Scripts\activate
  ```

После активации в начале строки терминала появится `(.venv)`.

Установите необходимые библиотеки:
```bash
pip install -r requirements.txt
```

### Шаг 2: Настройка токена бота

Откройте файл `config.py` в любом текстовом редакторе и замените токен на ваш:

```python
TG_TOKEN = 'ВАШ_ТОКЕН_ОТ_BOTFATHER'
```

⚠️ **ВАЖНО:** Никогда не публикуйте токен в открытом доступе! Это как пароль от вашего бота.

### Шаг 3: Настройка группы для проверки доступа

Бот проверяет, является ли пользователь участником определенной группы. Чтобы настроить это:

1. Откройте файл `middleware.py` в текстовом редакторе
2. Найдите строку `CHAT_LIST = [-5060610445]` (примерно строка 11)
3. Замените `-5060610445` на ID вашей группы

#### Как узнать ID группы:

**Способ 1 (через бота):**
1. Добавьте бота в группу и сделайте его администратором
2. Запустите бота (см. раздел "Запуск бота")
3. Напишите боту в личные сообщения команду `/check`
4. Нажмите кнопку "📢 Выбрать группу" и выберите нужную группу
5. Бот покажет ID группы

**Способ 2 (через веб-версию Telegram):**
1. Откройте группу в [web.telegram.org](https://web.telegram.org)
2. Посмотрите URL - там будет ID группы

⚠️ **Примечание:** ID группы обычно отрицательное число (начинается с минуса).

## 🚀 Запуск бота

### Обычный запуск

Убедитесь, что виртуальное окружение активировано (в терминале должно быть `(.venv)` в начале строки).

Запустите бота:
```bash
python3 bot.py
```

Если всё настроено правильно, вы увидите сообщение:
```
Успешный запуск.
```

Бот теперь работает! Вы можете протестировать его, написав `/start` в Telegram.

### Остановка бота

Чтобы остановить бота, нажмите `Ctrl + C` в терминале.

## 👥 Управление пользователями

### Просмотр пользователей

Все пользователи хранятся в файле `data/users.json`. Вы можете открыть его в текстовом редакторе для просмотра.

Структура данных пользователя:
```json
{
  "123456789": {
    "tg_id": 123456789,
    "username": "имя_пользователя",
    "registration_date": "2025-12-05T10:00:00",
    "last_request_date": "2025-12-05T15:30:00",
    "is_member": true,
    "last_checked": "2025-12-05T15:30:00"
  }
}
```

### Ручное управление через файл

⚠️ **ВНИМАНИЕ:** Редактируйте файл только когда бот остановлен!

1. Остановите бота (`Ctrl + C`)
2. Откройте `data/users.json`
3. Внесите изменения
4. Сохраните файл
5. Запустите бота снова

**Примеры операций:**

- **Удалить пользователя:** Удалите весь блок с его `tg_id`
- **Изменить статус доступа:** Измените `"is_member": false` на `"is_member": true` (или наоборот)
- **Сбросить дату последнего запроса:** Измените `"last_request_date"` на текущую дату в формате ISO

### Программное управление (для продвинутых)

Вы можете использовать функции из файла `dbtools.py` через Python:

```python
import dbtools

# Получить информацию о пользователе
user = dbtools.get_user(123456789)

# Получить всех пользователей
all_users = dbtools.get_all_users()

# Удалить пользователя
dbtools.delete_user(123456789)

# Установить статус членства
dbtools.set_member_status(123456789, True)  # True = есть доступ, False = нет доступа
```

## 📊 Мониторинг и логи

### Логи запросов

Все действия пользователей записываются в папку `logs/`. Каждый день создается отдельный файл:
- `logs/2025-12-05.log` - логи за 5 декабря 2025 года
- `logs/2025-12-06.log` - логи за 6 декабря 2025 года
- И так далее...

Формат записи в логах:
```json
{"ts": "2025-12-05T15:30:00+05:00", "user_id": 123456789, "username": "имя", "action": "command:/start"}
```

### Просмотр логов

**В терминале (Mac/Linux):**
```bash
# Посмотреть последние 50 строк лога за сегодня
tail -n 50 logs/$(date +%Y-%m-%d).log

# Найти все действия конкретного пользователя
grep "123456789" logs/*.log
```

**В терминале (Windows):**
```bash
# Посмотреть последние строки лога
type logs\2025-12-05.log | more
```

**В текстовом редакторе:**
Просто откройте нужный файл в `logs/` любым текстовым редактором.

### Статистика

Для получения статистики за день запустите:
```bash
python3 stats.py
```

Это создаст или обновит файл `data/stats.json` с метриками:
- `users_total` - общее количество пользователей
- `requests` - количество запросов за день
- `active_1d` - активные пользователи за последние 24 часа
- `active_7d` - активные пользователи за последние 7 дней

## 🔍 Решение проблем

### Бот не запускается

**Ошибка: "ModuleNotFoundError"**
- Убедитесь, что виртуальное окружение активировано
- Переустановите зависимости: `pip install -r requirements.txt`

**Ошибка: "Invalid token"**
- Проверьте токен в `config.py`
- Убедитесь, что токен скопирован полностью, без пробелов

**Ошибка: "Permission denied"**
- На Mac/Linux: добавьте права на выполнение: `chmod +x bot.py`
- Проверьте права доступа к папке `data/` и `logs/`

### Бот запускается, но не отвечает

1. Проверьте интернет-соединение
2. Убедитесь, что токен правильный
3. Проверьте логи в терминале на наличие ошибок
4. Убедитесь, что бот не заблокирован в Telegram

### Пользователи не могут получить доступ

1. Проверьте ID группы в `middleware.py`
2. Убедитесь, что бот добавлен в группу и является администратором
3. Проверьте, что пользователь действительно состоит в группе
4. Посмотрите логи для диагностики

### Ошибки в работе бота

**Проверьте логи:**
```bash
tail -f logs/$(date +%Y-%m-%d).log
```

Это покажет последние записи в реальном времени. Остановите просмотр нажатием `Ctrl + C`.

**Частые проблемы:**

- **"message is not modified"** - это нормально, можно игнорировать
- **"message not found"** - пользователь удалил сообщение, это нормально
- **Ошибки подключения** - проверьте интернет

## 🔄 Автозапуск (опционально)

### На Mac (через launchd)

Создайте файл `~/Library/LaunchAgents/com.ugra.bot.plist`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.ugra.bot</string>
    <key>ProgramArguments</key>
    <array>
        <string>/Users/gleb/Desktop/to/ugra-to-bot/.venv/bin/python3</string>
        <string>/Users/gleb/Desktop/to/ugra-to-bot/bot.py</string>
    </array>
    <key>WorkingDirectory</key>
    <string>/Users/gleb/Desktop/to/ugra-to-bot</string>
    <key>RunAtLoad</key>
    <true/>
    <key>KeepAlive</key>
    <true/>
</dict>
</plist>
```

Загрузите службу:
```bash
launchctl load ~/Library/LaunchAgents/com.ugra.bot.plist
```

### На Linux (через systemd)

Создайте файл `/etc/systemd/system/ugra-bot.service`:

```ini
[Unit]
Description=Ugra Telegram Bot
After=network.target

[Service]
Type=simple
User=ваш_пользователь
WorkingDirectory=/Users/gleb/Desktop/to/ugra-to-bot
ExecStart=/Users/gleb/Desktop/to/ugra-to-bot/.venv/bin/python3 /Users/gleb/Desktop/to/ugra-to-bot/bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```

Активируйте службу:
```bash
sudo systemctl enable ugra-bot.service
sudo systemctl start ugra-bot.service
```

### На Windows (через Task Scheduler)

1. Откройте "Планировщик заданий"
2. Создайте новое задание
3. Триггер: "При входе в систему"
4. Действие: Запустить программу
   - Программа: `C:\Users\gleb\Desktop\to\ugra-to-bot\.venv\Scripts\python.exe`
   - Аргументы: `bot.py`
   - Рабочая папка: `C:\Users\gleb\Desktop\to\ugra-to-bot`
