## 🔧 Требования

### Что нужно установить:

1. **Python 3.10 или новее** (aiogram 3.22 несовместим со старше 3.8)
   - Проверьте версию: `python3 --version` (Windows: `python --version` или `py --version`)
   - Если Python не установлен, скачайте с [python.org](https://www.python.org/downloads/)
   - ⚠️ При установке обязательно отметьте галочку "Add Python to PATH"

2. **Telegram Bot Token**
   - Создайте бота через [@BotFather](https://t.me/BotFather) в Telegram
   - Отправьте команду `/newbot` и следуйте инструкциям
   - Сохраните полученный токен (выглядит как `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

## ⚙️ Первоначальная настройка

### Шаг 1: Установка зависимостей

Откройте терминал или встроенную консоль в любом редакторе (VS Code: `Ctrl+``).

Склонируйте репозиторий с GitHub и перейдите в папку проекта:
```bash
git clone https://github.com/Rezak159/ugra-to-bot
cd ugra-to-bot
```

Создайте виртуальное окружение (изолированная среда для проекта):
```bash
python3 -m venv .venv
```

Активируйте виртуальное окружение:
- **На Mac/Linux:**
  ```bash
  source .venv/bin/activate
  ```
- **На Windows:**
  ```bash
  .venv\Scripts\activate
  ```

После активации в начале строки терминала появится `(.venv)`.

Установите необходимые библиотеки:
```bash
pip install -r requirements.txt
```

### Шаг 2: Создание и настройка файла конфигурации

⚠️ **ВАЖНО:** `config.py` хранит **только `TG_TOKEN`**. Все ID групп и администраторов вынесены в `ids.yaml` (см. следующий шаг). Файл `config.py` не хранится в репозитории, его нужно создать вручную при первом запуске.

**Создание файла config.py:**

1. **Способ 1 (через терминал - рекомендуется):**
   ```bash
   cp config.example.py config.py
   ```

2. **Способ 2 (вручную):**
   - Откройте файл `config.example.py` в текстовом редакторе
   - Скопируйте всё его содержимое
   - Создайте новый файл `config.py` в той же папке
   - Вставьте скопированное содержимое
   - Сохраните файл

**Настройка токена бота:**

Откройте созданный файл `config.py` и замените `ВАШ_ТОКЕН_ОТ_BOTFATHER` на ваш токен от [@BotFather](https://t.me/BotFather):

```python
TG_TOKEN = '1234567890:ABCdefGHIjklMNOpqrsTUVwxyz'
```

⚠️ **ВАЖНО:** Никогда не публикуйте токен в открытом доступе! Это как пароль от вашего бота.

### Шаг 3: Настройка доступа (ids.yaml)

Бот проверяет членство по файлу `ids.yaml` в корне проекта. В нём же задаются администраторы, которым доступны служебные команды.

**Структура файла:**
```yaml
CHAT_LIST:
  - -1234567890   # ID групп/каналов с доступом

ADMINS:
  - 111111111     # ID администраторов бота
```

- Отредактируйте `CHAT_LIST`, указав ID групп или каналов, участники которых должны иметь доступ.
- Заполните `ADMINS` ID администраторов. Только они смогут пользоваться командами `/check`, `/list_chats`, `/add_chat`, `/remove_chat`.
- Изменения в `ids.yaml` применяются сразу, перезапускать бота не нужно.

#### Как узнать ID группы:

**Способ 1 (через бота, только для админов):**
1. Запустите бота (см. раздел "Запуск бота")
2. Напишите команду `/check`
3. Нажмите кнопку "📢 Выбрать группу" и выберите нужную группу
4. Бот покажет ID группы
 
**Способ 2 (через веб-версию Telegram):**
1. Откройте группу в [web.telegram.org](https://web.telegram.org)
2. Посмотрите URL — там будет ID группы

⚠️ **Примечание:** ID группы обычно отрицательное число (начинается с минуса).

#### Быстрое управление доступом (админ-команды)
- Команды работают **только в личке** с ботом.
- Бот должен быть админом в группах, которые вы добавляете/удаляете.
- `/list_chats` — показать текущий список групп из `CHAT_LIST`
- `/add_chat` — добавить группу в `CHAT_LIST` кнопкой выбора (ID сохраняется в `ids.yaml`)
- `/remove_chat` — удалить группу из `CHAT_LIST`
- `/check` — показать ID выбранной группы

## 🚀 Запуск бота

### Обычный запуск

**Перед запуском убедитесь:**
1. Виртуальное окружение активировано (`source .venv/bin/activate`, Windows: `.venv\Scripts\activate`)
2. Вы находитесь в корне проекта (`ugra-to-bot`)
3. Файл `config.py` создан из `config.example.py` и заполнен токеном (см. Шаг 2)

Запустите бота (Mac/Linux):
```bash
python3 bot.py
```

Запуск на Windows:
```bash
python bot.py
```

Если всё настроено правильно, вы увидите сообщение:
```
Успешный запуск.
```

Бот теперь работает! Вы можете протестировать его, написав `/start` в Telegram.

### Остановка бота

Чтобы остановить бота, нажмите `Ctrl + C` в терминале.

## 👥 Управление пользователями

### Просмотр пользователей

Все пользователи хранятся в файле `data/users.json` (создается автоматически при первом запуске).

Пример записи (минимально):
```json
{
  "123456789": {
    "tg_id": 123456789,
    "username": "user",
    "is_member": true
  }
}
```

### Ручное управление через файл

⚠️ **ВНИМАНИЕ:** Редактируйте файл только когда бот остановлен!

1. Остановите бота (`Ctrl + C`)
2. Откройте `data/users.json`
3. Внесите изменения
4. Сохраните файл
5. Запустите бота снова

**Примеры операций:**

- **Удалить пользователя:** Удалите весь блок с его `tg_id`
- **Изменить статус доступа:** Измените `"is_member": false` на `"is_member": true` (или наоборот)
- **Сбросить дату последнего запроса:** Измените `"last_request_date"` на текущую дату в формате ISO

### Программное управление (для продвинутых)

Вы можете использовать функции из файла `dbtools.py` через Python:

```python
import dbtools

# Получить информацию о пользователе
user = dbtools.get_user(123456789)

# Получить всех пользователей
all_users = dbtools.get_all_users()

# Удалить пользователя
dbtools.delete_user(123456789)

# Установить статус членства
dbtools.set_member_status(123456789, True)  # True = есть доступ, False = нет доступа
```

## 📊 Мониторинг и логи

### Логи и данные

Папки `data/` и `logs/` создаются автоматически при первом запуске.

- Логи запросов: `logs/YYYY-MM-DD.log`
- Логи ошибок: `logs/bot.log` (ротация при 10 МБ, до 5 файлов)

Быстрый просмотр (Mac/Linux):
```bash
tail -n 50 logs/$(date +%Y-%m-%d).log
tail -n 50 logs/bot.log
grep "123456789" logs/*.log
```

Быстрый просмотр (Windows):
```bash
type logs\%DATE:~-4,4%-%DATE:~3,2%-%DATE:~0,2%.log | more
type logs\bot.log | more
```

### Статистика

Для получения статистики за день запустите:
```bash
python3 stats.py
```

Это создаст или обновит файл `data/stats.json` с метриками:
- `users_total` - общее количество пользователей
- `requests` - количество запросов за день
- `active_1d` - активные пользователи за последние 24 часа
- `active_7d` - активные пользователи за последние 7 дней

## 📝 Структура проекта

```
ugra-to-bot/
├── bot.py              # Главный файл бота
├── config.example.py   # Пример файла конфигурации (шаблон)
├── config.py           # Конфигурация (токен) - создается вручную, не хранится в репозитории
├── ids.yaml            # Список групп с доступом и администраторов
├── requirements.txt    # Зависимости Python
├── dbtools.py          # Работа с базой данных пользователей
├── middleware.py       # Проверка доступа
├── stats.py            # Статистика
├── utils.py            # Вспомогательные функции
├── keyboards.py        # Клавиатуры бота
├── texts.json          # Тексты меню и сообщений
├── data/               # Папка создается автоматически
│   ├── users.json      # База данных пользователей
│   └── stats.json      # Статистика
└── logs/               # Папка создается автоматически
    ├── YYYY-MM-DD.log  # Логи запросов по дням
    └── bot.log         # Логи ошибок (с ротацией)
```
